# dhsb_checkpoint_5

Brings a **fresh** Drupal 11.5 Standard site to the end of Module 5 of the DrupalHelps Site Building course. It can't repair a half-built site: a recipe refuses to overwrite configuration that already exists.

Local, in the project folder of a fresh Drupal 11.5 Standard site (DDEV):

```bash
ddev composer config repositories.jarvis '{"type":"vcs","url":"https://github.com/imrodmartin/jarvis","no-api":true}'
ddev composer config repositories.jarvis-modules '{"type":"vcs","url":"https://github.com/imrodmartin/jarvis-modules","no-api":true}'
ddev composer config repositories.dhsb_setup '{"type":"vcs","url":"https://github.com/imrodmartin/dhsb_setup","no-api":true}'
ddev composer config repositories.dhsb_checkpoint_5 '{"type":"vcs","url":"https://github.com/imrodmartin/dhsb_checkpoint_5","no-api":true}'
ddev composer require imrodmartin/dhsb_checkpoint_5:^1.0
ddev exec "cd web && ../vendor/bin/dr recipe:apply ../recipes/dhsb_checkpoint_5"
ddev drush cache:rebuild
```

## What it leaves out

- Accounts (from Module 4) have no passwords. Set one with `ddev drush user:password marcus "a-password"`, or log in with `ddev drush uli --name=marcus`.
- The Content editor role from Standard is still there. A recipe can't delete configuration. Delete it at People > Roles if you want an exact match.
- Module 3: the donor video (pick any YouTube video yourself).
- Module 6: the 200 generated shifts, the Opportunity content template (6.12), and the Next 6 shifts block on the Home page (the block display exists, so drag it in from Canvas's Library).
- Module 7: the AI alt text setup, which needs your own provider account and key.

Generated from a validated build on Drupal 11.5.0-beta1, November 23, 2026. It is generated by the course build pipeline, so change the course, then regenerate, rather than editing these files by hand.
